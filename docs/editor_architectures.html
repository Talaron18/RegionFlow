SD3-UltraEdit (with mask)

BleachNick/SD3_UltraEdit_w_mask · 2024

The baseline you have scored. SD3-Medium with a wider input layer.

Fits 24 GB. Already run for Gate C
  • The source image and mask never become their own tokens. They are extra channels on the noisy latent, so the model can only compare source and output at the same pixel position.
  • Text is read by encoders that never see the image.
  • Trained on about 4M synthetic pairs whose targets were made by SDXL-Turbo in 2–7 steps.

FLUX.2 klein 4B

black-forest-labs/FLUX.2-klein-4B · Jan 2026

Smallest open FLUX.2. One model for generation and editing.

Fits 24 GB. Card: about 13 GB, names the RTX 3090
  • The text encoder is a language model, replacing CLIP and T5.
  • The VAE keeps 32 channels per position, twice SD3's 16.
  • That reference images enter as tokens is my reading of the pipeline's image argument and the FLUX Kontext design it descends from; I did not read the klein source.

Qwen-Image-Edit-2511

Qwen/Qwen-Image-Edit-2511 · Dec 2025

The large, permissively licensed editor. The source image is read twice.

Too large for 24 GB. About 40 GB of weights; needs heavy quantisation
  • Two paths for the source image: the vision-language model carries what the image means, the VAE carries what it looks like.
  • The dashed arrow marks the image feeding the text encoder.
  • Deepest stack of the group at 60 blocks.

Qwen-Image-2.1

Qwen/Qwen-Image-2.1 · Sept 2026

Newer, much smaller than 2511, and the only one whose card documents mask input.

Fits by file size only. 14.2 GB denoiser, 17.5 GB encoder; must load one at a time. Not confirmed.
  • Fully single-stream: text, reference and output tokens share one set of weights from the first block.
  • 64 latent channels at 1/16 resolution, the richest latent here.
  • Research-only licence.

FLUX 3 Image Klein

black-forest-labs/flux-3-image-klein · Oct 2026

From the model card you supplied. Adds a mandatory prompt rewriter and bounding boxes.

Does not fit 24 GB as documented. Card: peak 31 GB (BF16), 26 GB (FP8), 25 GB (NVFP4) at 1024², before the 9B prompt upsampler (about 28 GB more)
  • Region control is language, not pixels: boxes are typed into the prompt, and the card says edits can change content outside the box.
  • A short instruction sent as typed gives generic output; the upsampler is required.
  • A separate Base checkpoint exists for LoRA training.

What changes from the old design to the new ones

  • The text reader. SD3 uses encoders that only ever see text. The newer models use a language model, and three of the five use a vision-language model that reads the source image together with the instruction.
  • How the source image enters. UltraEdit stacks it as extra channels on the noisy latent. The newer models give it its own tokens, so attention can relate any part of the source to any part of the output.
  • The latent. 16 channels in SD3; 32 in FLUX.2 klein; 64 in Qwen-Image-2.1.
  • The block type. SD3 keeps text and image in two streams throughout. FLUX.2 klein is mostly single-stream, and Qwen-Image-2.1 is entirely single-stream.
  • Region control is still rare. Only UltraEdit takes a pixel mask as a first-class input. Qwen-Image-2.1 documents masks; FLUX 3 Klein uses boxes written as text, which its card says do not confine the edit.
